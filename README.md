# Fund Payment & Spending Tracker Automation

## Overview
This project is an automated financial tracking and reporting system built using Microsoft Excel. It helps track fund payments, spending records, running balances, and overall budget status through dynamic dashboards and automated calculations.

The project is designed to reduce manual work, improve financial accuracy, and provide real-time insights for reporting and decision-making.

---

# Features
- Automated payment and spending tracking
- Dynamic financial dashboard with KPIs
- Running balance and cumulative calculations
- Budget monitoring system
- Conditional formatting for financial alerts
- Real-time reporting updates
- User-friendly “How To Use” instruction sheet
- Organized multi-sheet workbook structure

---

# Worksheets Included

| Sheet Name | Purpose |
|---|---|
| Dashboard | Displays KPIs, summaries, and financial insights |
| Payments | Tracks fund received from different tranches |
| Spendings | Records all spending and expense details |
| How To Use | Provides user instructions and workflow guidance |

# How To Use
1. Enter payment details in the **Payments** sheet.
2. Add expense records in the **Spendings** sheet.
3. Dashboard updates automatically with latest calculations.
4. Refer to the **How To Use** sheet for detailed guidance.
